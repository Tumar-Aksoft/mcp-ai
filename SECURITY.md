# Безопасность

Не публикуй в Issues токены, коды привязки, данные пользователей и подробности эксплуатации уязвимости.

Приватный канал сообщений об уязвимостях пока не настроен. При обнаружении проблемы сначала создай Issue только с просьбой предоставить приватный канал связи — без технических подробностей и чувствительных данных.

Публичный репозиторий содержит документацию; исходники, конфигурация рабочего сервиса и учётные данные сюда не включаются.
